# Rui Zhao - Personal Homepage

Source code for [zhaorui.xyz](https://zhaorui.xyz), Rui Zhao's personal academic homepage.

## Overview

This repository hosts a static website for professional profile, publications, and updates.
The site is deployed with GitHub Pages.

## Main Pages

- `index.html`: homepage
- `publications.html`: publication list
- `links.html`: professional links
- `welcome.html`: alternative landing page

## Local Preview

No build step is required.

- Open HTML files directly in a browser, or
- Run a simple local server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deployment

Pushing to the `master` branch triggers GitHub Pages deployment.
